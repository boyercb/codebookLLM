# codebookLLM: PHI-Safe, LLM-Oriented Code Books for Data Frames

Generates compact, machine-parseable code books that describe the
structure of a data frame - names, classes, roles, missingness,
cardinality, factor levels and the shape of numeric variables - without
exposing row-level data. The output is designed to be pasted into a
large language model prompt so that code can be written against a
dataset that may contain protected health information.
